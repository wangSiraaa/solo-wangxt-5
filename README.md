# 骑马订小册子拼版工具（纯浏览器）

小型印刷工作室用的骑马钉（saddle-stitch）拼版工具。**全部在浏览器内运行**：PDF.js 渲染原页预览，pdf-lib 生成拼版 PDF，工程参数保存在浏览器 IndexedDB，无服务端、无数据库。

## 运行

```bash
npm install
npm run dev        # 开发
npm run build      # 类型检查 + 生产构建
npm run preview    # 预览构建产物
```

测试：

```bash
npm run test:logic    # 拼版页序 / 补白 / 旋转 / 封面单独计纸 的算法断言
npm run test:export   # 端到端：生成样册→导出→用 PDF.js 读回，逐格核对页序、补白、页面尺寸
```

## 使用流程

1. **导入**：拖入 PDF，或点“载入 8 页样册 / 11 页样册”。样册每页印有大页号、TOP/BOTTOM/LEFT/RIGHT 角标和书脊箭头，可直接肉眼核对翻转方向。
2. **设置**（左侧栏）
   - 纸张：A3/A4/A5/B4/B5/Letter/Tabloid/自定义（横向尺寸，mm）；
   - **短边翻转**（骑马订常规，背面正立）/ **长边翻转**（背面整面旋转 180°，预览中以 ⟲ 标出）；
   - 出血（mm）、meet（整页保留/留白）与 fill（填满出血/裁切）适配、爬移补偿、裁切标记；
   - **封面单独计纸**：封面/封底独占一张纸（封二、封三为补白），书芯另行配对；可选封面使用哪一页，封底默认取最后一页。
3. **检查**：
   - 每张纸显示**正面 / 背面**画布，角标写明 `原页 n → 成书页 m`；
   - 红虚线 = 裁切线，橙线 = 出血范围，蓝虚线 = 中缝折线，红斜纹 = 补白位置；
   - 页数不足 4 的倍数时，补白在书芯末尾，并在画布、侧栏检查、导出对话框表格中明确标出成书页号与所在半版；
   - 改变纸张规格或出血后自动重新检查出血/裁切范围（比例差异、meet 白边、出血越界等）。
4. **排除页**：点击原页缩略图排除/恢复，页序按剩余页重排；**撤销/重做**支持 Ctrl/Cmd+Z、Ctrl/Cmd+Shift+Z（滑杆连续调整自动合并）。
5. **导出**：点“导出前检查并下载”，在对话框中处理错误/警告并查看逐纸页序表，确认后生成 PDF。

## 预览与成品的关系（重要）

- 屏幕画布上的原页内容是 PDF.js 渲染的 **约 900px 低分辨率位图，仅用于检查页序、补白与旋转**，界面有常驻黄条提醒。
- 导出的 PDF 通过 `out.embedPage(srcPage)` + `drawPage` **嵌入源 PDF 的原始矢量页面**（同页只嵌入一次，其余引用），任何预览位图都不会进入成品。
- 预览画布与导出器共用 `src/lib/placement.ts` 的 `computePlacement`（同一份缩放/居中/旋转几何），因此下载后的页序、补白位置、180° 旋转与预览一致。

## 骑马订页序规则

成书补到 4 的倍数后共 `T` 页、`T/4` 张纸，帖序 `k`（0 = 最外层）：

| 半版 | 成书页位 |
| --- | --- |
| 正面左 | T − 2k |
| 正面右 | 1 + 2k |
| 背面左 | 2 + 2k |
| 背面右 | T − 1 − 2k |

- 8 页：纸1 `8|1 / 2|7`，纸2 `6|3 / 4|5`；
- 11 页补到 12：纸1 `补白12|1 / 2|11`，纸2 `10|3 / 4|9`，纸3 `8|5 / 6|7`；
- 长边翻转时每张纸**背面两个半版各旋转 180°**；
- 封面单独计纸时，封面纸固定为 `封底|封面 / 封二补白|封三补白`，内页序列独立配对。

## 数据存储

- IndexedDB 库 `booklet-tool`：`__draft__`（草稿，含设置、排除页及源 PDF 字节，刷新后可一键恢复）、`proj:<工程名>`（命名工程参数，源 PDF 不入库，恢复时提示重新导入对应文件）。
- 不发起任何网络请求，不配置服务端数据库。

## 目录

```
src/lib/
  types.ts        类型定义
  papers.ts       纸张规格、默认设置
  imposition.ts   骑马订配对 / 封面纸 / 补白 / 爬移（核心算法）
  placement.ts    源页→半版的缩放、居中、旋转（预览与导出共用）
  render-sheet.ts canvas 预览（位图 + 裁切线/出血/折线/补白覆盖层）
  pdf-service.ts  PDF.js 封装与低分辨率预览缓存
  exporter.ts     pdf-lib 矢量导出（embedPage，绝不使用预览位图）
  preflight.ts    导出前检查
  history.ts      撤销/重做（连续调整合并）
  db.ts           IndexedDB
  sample.ts       内置 8/11 页矢量样册
scripts/
  smoke.ts            算法断言
  verify-export.mts   导出 PDF 回读核对
  browser-test.cjs    无头浏览器端到端冒烟
```
